## S2.1 — Project session: open/close as a unit

- **Do:** a session object per window holding the open project: sets `labshelf.writing.projectOpen` and `labshelf.writing.inProject`, remembers the project in `workspaceState` and restores it on reload.
- **Do:** open = open main document + the project's single preview panel (D4). Opening another source of the project never opens a second preview; opening a project source while the preview is closed reopens it.
- **Do:** close = close the project's source tabs via `tabGroups.close` and respect its result (R1); cancel on an unsaved prompt keeps the project open. Closing only the preview keeps the project open.
- **Do:** move `openProjectMain.ts` and `projectStore.ts` into `vscode/src/writing/session/`.
- **Touch:** `vscode/src/writing/session/`, `writing/preview/` (panel creation), `activation/registration/registerWritingView.ts`. **Do not touch:** the tree providers (session 4).
- **Test first:** open → one main tab + one preview; open a second source → still one preview; close with a dirty tab and cancel → project still open.
- **Done when:** A4, A5.

## S2.2 — Focus follower

- **Do:** on `onDidChangeActiveTextEditor`, find the owning project (`owningProject`). If it is the open project, pick the root (D5, using S1.1) or the main, and show its cached PDF in the preview, or request a build if none exists or it is stale (D7). A non-project tab leaves the preview as it is.
- **Touch:** `vscode/src/writing/preview/` (new file). **Do not touch:** build orchestration beyond calling it.
- **Test first:** focus root → its PDF; focus included chapter → main PDF; focus unrelated tab → unchanged; focus switch with a fresh PDF → no build.
- **Done when:** A6.
