# Session 2a — decisions for every package

Every 2a implementer reads this file in full.

- **Port.** The neutral code takes `LibraryFileSystem` (`packages/core/src/ports/libraryFileSystem.ts`: `IFileSystem` + `LocalFileSystem` + rename/trash/mkdir) and the neutral `PathOps` / `joinWith` already in core (see `packages/vscode/src/activation/serviceComposition/hostAdapters.ts` for the import). Add to the port only what is missing: a recursive delete that does not go through the trash (`removeTree`). Copy is read plus write. Implement `removeTree` in all three adapters: `packages/core/src/library/node/nodeLibraryFileSystem.ts`, `packages/vscode/src/storage/vscodeFileSystem.ts` (`vscode.workspace.fs.delete` with `recursive: true, useTrash: false`) and `packages/browser/src/storage/byteBacked/byteBackedFileSystem.ts`.
- **Atomic writes.** `LibraryFileSystem.writeFile` is atomic in every adapter. Write that down as an `INVARIANT:` on the port, and make the node adapter do tmp + rename + fsync like `library/node/atomicWrite.ts`. Neutral code calls `writeFile` and never reimplements the atomic write.
- **One implementation.** Each neutral function replaces its `node/` copy in the same package. The node copy is deleted, and node callers run the neutral one over `NodeLibraryFileSystem`. A `node/` file stays only for real Node work: child processes (pandoc, latexdiff, git user name, LaTeX build), `os.homedir`/XDG directories, and `realpathSync`/sha256 in `deviceLocalLayout`.
- **Placement.** Neutral code goes at the root of its domain folder, never under `node/`. Where a domain folder passes 8 source files, group by responsibility.
- **Formats.** `labshelf.yaml`, `projects.json`, versions, values, checklist and synctex files are read and written byte-for-byte as they are today. `documents/contracts/` does not change. Tests pin each format through the neutral functions.
- **Synctex.** Gunzip uses the web-standard `DecompressionStream("gzip")`, which Node ≥ 18 and browsers both have. No `node:zlib`.
- **Logging.** Every failure and every fallback is logged through the injected `ILogger`, with the path, as the node versions do.
- **Tests.** They go under `packages/core/__tests__/` mirroring src, over a small in-memory `LibraryFileSystem` fake written once in `__tests__` (reuse one if it exists: `grep -rln "LibraryFileSystem" packages/core/__tests__`). Existing tests of the deleted node functions are moved onto the neutral functions, not dropped.
