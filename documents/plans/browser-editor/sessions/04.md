## 4.1 — Join shared projects

- **Goal:** a project shared from VS Code can be joined from the page, and edits, cursors and comments flow both ways.
- **Decided:** the page speaks the protocol in `documents/contracts/collaboration.md` (D6). It runs the core session from `packages/core/src/collab/` and the trystero transport from `collab/dom/` natively; `y-monaco` binds each of the page's Monaco models to the file's Yjs document. The invite link is pasted in the page or passed from the Writing tab; its `#fragment` carries the project key, so the page adds no account. The page uses the project's relay list (`documents/contracts/relay.md`). Comments go through the core comment store on the index document's `comments` map, so they show live in VS Code (A4). Code lives only in `packages/browser/src/editor/collab/`; nothing is copied from `packages/vscode/`.
- **Read only:** `packages/browser/src/editor/` index and the file system provider from session 3; `packages/core/src/collab/index.ts` and `collab/dom/index.ts`; `documents/contracts/collaboration.md`, `relay.md`; the `y-monaco` README after install.
- **Done when:** a test joins two in-memory peers through the core session, with one bound to a Monaco model, and an edit and a comment reach the other peer; `pnpm --filter @labshelf/browser typecheck && pnpm --filter @labshelf/browser test && pnpm --filter @labshelf/browser build`.
- **Do not touch:** `packages/vscode/`, `core` contracts, the rest of `packages/browser/src/editor/`.
