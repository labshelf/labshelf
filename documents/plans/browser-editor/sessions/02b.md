## 2b.1 — Device directories and the factory

- **Goal:** `createProjectData({ fs, path, logger, deviceDirs })` at the root of `writing/projectData/` returns the full `ProjectDataPort`. `deviceDirs` holds `projectRegistryPath`, `buildCacheDir` and `mergeBasesDir`, all strings. `projectBuildDir`, `unregisterProjectFolder`, the registry reads and writes, `FileMergeBaseStore` and `scanLibraryConflicts` take these values instead of calling `deviceLocalLayout`/`cacheDir`/`os.homedir`. On Node, `deviceLocalLayout` stays in `library/node/` and the composition roots compute `deviceDirs` from it. `nodeProjectData` is deleted.
- **Wiring:** `packages/vscode/src/activation/node/nodeAdapters.ts:23` and the terminal root build `createProjectData` over `NodeLibraryFileSystem`. Every file in `packages/vscode/src/writing/` that imports a function this session made neutral imports it from `@labshelf/core`. Files that use `node:path` only to handle paths switch to the injected `PathOps`, as found while planning session 2: `activation/registration/registerWritingView.ts`, `writing/allProjects/{projectLibrary,projectRows,projectHostActions}.ts`, `writing/checklist/{openProjectSignals,checklistView,checklistRows,registerChecklistView}.ts`, `writing/preview/{stale/staleSources,citationFixes/replaceCitedKey,citationFixes/addBibToLibrary,citations/citingCommands}.ts`.
- **Library services:** `packages/vscode/src/activation/.../buildServices.ts` and `externalChangeHandling.ts` take `deviceDirs` and the merge-base store from `HostAdapters` instead of importing `@labshelf/core/node`, so session 2's web root can supply web versions (under `context.globalStorageUri`).
- **Read only:** `writing/projectData/*`, `writing/project/node/{projectRegistryFile,projectBuildDir}.ts`, `library/node/deviceState/deviceLocalLayout.ts`, `library/node/cacheDirectory.ts`, `writing/merge/node/{fileMergeBaseStore,libraryConflictScan}.ts`, `packages/vscode/src/activation/serviceComposition/hostAdapters.ts`, `packages/vscode/src/activation/node/nodeAdapters.ts`.
- **Done when:** `grep -rn "@labshelf/core/node\|from \"node:" packages/vscode/src/writing packages/vscode/src/activation` returns only desktop-only features (`writing/*/node/`, LaTeX build, typst host, pandoc export, latexdiff compare, bridge) and `activation/node/`; core, vscode, browser and terminal typecheck and test; desktop behaviour unchanged.
- **Do not touch:** `packages/vscode/build/`, the manifest `browser` field and the web composition root (session 2), `documents/contracts/`.
