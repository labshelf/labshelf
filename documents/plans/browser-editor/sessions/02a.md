## 2a.2 — Write side

- **Goal:** neutral `createProjectFromTemplate` (staging folder, then rename into place), `updateProjectSettings`, `updateProjectBibliography` (with the injected `OpenSources`), `markVersion` (temp folder, then rename; the random suffix from `crypto.getRandomValues`), `deleteProjectForever` (refuses any folder outside the library root; neutral `isInside` over `PathOps`), `addExistingFolder`, and `updateChecklist`.
- **Data loss (tests first):** each test fails without its guard. Delete refuses paths outside the library root and the root itself. A failed template create leaves no partial folder and keeps an existing folder untouched. A failed `markVersion` leaves no half-written version and keeps earlier versions. Settings and checklist writes keep every field they do not patch.
