  • Everything outside the paper text reads the VS Code theme variables, softened with transparency; the status marks, file-type colours, highlight colours and the serif for paper text stay LabShelf's in every theme.
  • Only three hairlines divide the view: side bar | list, list | details, and under the column titles. Everything else is separated by space and soft fills; only the menu and the toast cast a shadow.
  • The side bar's folder tree lists each folder's subfolders first, then its papers. A paper is a folder of files (paper.pdf, notes, attachments), so it gets its own written mark, REF, in the same mono as PDF and MD, followed by the title only (status lives in the list); the folder's twistie folds both. Clicking a paper there selects it in the list with its files open, scrolled into view; if the current scope or search hides it, the list moves to the paper's folder first. The selected paper is marked in the tree.
  • The list header names the scope; a folder shows its path from the library root (Library › Deep learning › Scaling), each parent clickable, and long parents shorten with an ellipsis. All papers and the status scopes have no path.
  • Folders nest. The side bar shows a folder's subfolders under a twistie (the folder's chevron turns down when open). The list groups papers by the folder they sit in, as flat sections at one level whatever the depth, in tree order (a parent before its children, siblings alphabetical); a folder with no papers of its own has no section.
  • A section header is the folder's path from the current scope: parents muted, the folder in bold, a count at the end. A folder's own papers come first, unlabelled and flush with the list edge, since the path above names their folder; each subfolder follows under its label, its papers one soft step inside. Paths of more than three segments keep the first and last two and show the rest as …; the full path is in the tooltip. Click any segment to open that folder; the twistie folds the section. Headers stay under the column titles while their section scrolls. A folder without subfolders shows no header.
  • The list shows Title, Authors, Year, Last read and Status. Click a title to sort; the sorted column shows its arrow, and hovering any other title shows a faint one. Sorting orders the papers inside each section; the sections keep tree order.
  • Status lives in two places that do the same thing: the side bar narrows the list, the Status mark (and Alt 1 Alt 2 Alt 3) changes a paper; hover the mark for its name.
  • A paper's folder opens below the row as tree children inside the Title column, each file led by its type in colour (PDF, MD, or a chevron mark for a subfolder): paper.pdf first, then notes, other files and subfolders, then Add file. metadata.yaml stays hidden.
  • The details pane has the core pane's content: the head holds the title, authors, a meta line ending in the folder, one action row (Open PDF, Cite and More) and a last row with the status button followed by the tags as #tokens (the + button opens the tag field); then Details, Annotations, Notes and Related. Abstract, Keywords and Info start open; Cited in, Cite and File start folded. A tag underlines on hover and shows its remove button on hover or focus.
