## S1 — Build

- **Do:** a `build` command calling the core runner; the first-run toolchain prompt in the terminal; output lines `path:line: severity: message` then the hint indented; exit codes 0 / 1 (errors) / 2 (toolchain missing). `--watch` rebuilds on change.
- **Touch:** `packages/terminal/src/cli/`. **Do not touch:** `core/src/writing/latex/node/` (consume it through its index), other apps.
- **Context:** the core build runner, the toolchain choice and the cache dir are the ones VS Code uses (from writing-core).
- **Test first:** command output format and exit codes (A1).
- **Done when:** A1.

## S2 — Cite

- **Do:** a full-screen picker reusing the TUI list and the core search; print the formatted citation (`--format latex|typst|key`); regenerate `labshelf.bib` in the project of the current directory.
- **Touch:** `packages/terminal/src/cli/`, `packages/terminal/src/ui/`. **Do not touch:** core search internals.
- **Context:** stdout carries only the citation, so editors can capture it; the UI draws on the TTY (`/dev/tty`, risk R1 in plan.md).
- **Test first:** formatted output per `--format` and the `labshelf.bib` update (A2).
- **Done when:** A2.

## S3 — Projects and the Writing pane

- **Do:** `labshelf projects` lists projects; the TUI gets a Writing pane next to folders and papers.
- **Touch:** `packages/terminal/src/cli/`, `packages/terminal/src/ui/`. **Do not touch:** other apps.
- **Test first:** pane lists projects (A3).
- **Done when:** A3.
