# Brief 1.3 — String helpers baseName, extensionOf, stemOf

- **Goal:** Add the string-only path helpers to `core/path` and replace the private copies that behave identically; rename the rest so no private function shares an export name.
- **Read only:** `documents/plans/reorganization/research/1.md`; `analysis/reorganization.md` §3.9 H and §4 `core/path` (lines 558–568, 685–698); the files named in the table below (read each only around the named function).
- **Decided:**
  - File `core/path/pathStrings.ts` (one concept, "names inside a `/`-separated string path"), exported from `core/path/index.ts`:
    - `baseName(path: string): string` is `path.slice(path.lastIndexOf("/") + 1)`.
    - `extensionOf(path: string): string` is the lower-case extension of the last segment including the dot, `""` when there is none; a leading dot (`.gitignore`) is not an extension.
    - `stemOf(path: string): string` is `baseName(path)` without its last extension; a leading dot is kept (`.gitignore` stays whole), the same rule as `fileStem` in `paperImport.ts` (`replace(/(?<=.)\.[^.]*$/, "")`).
    - `parentOf` / `folderOf` / `directoryOf` are not added: the existing copies differ (segment arrays, trailing slash kept, library-relative labels).
  - Per site (D2: behaviour of each caller is kept):
    - `browser/src/libraryUi/editorArea/tabKinds.ts` `baseName`: identical, delete and import `baseName`.
    - `core/src/library/mutations/import/paperImport.ts` `fileStem`: identical for file names, delete and call `stemOf`.
    - `core/src/writing/project/buildRoot/buildRootDetection.ts` `extensionOf`: it returns the last character for a name without a dot. If every use only tests membership in a set of dotted extensions (read the use), replace it with the shared `extensionOf`; otherwise rename the local function `lastDotSuffix` and leave its body.
    - `core/src/import/bibtex/BibtexService.ts` `baseName` (splits on `/` and `\`): rename to `fileNameAnySeparator`, keep body.
    - `core/src/writing/allProjects/dom/tray/projectTrayFacts.ts` `baseName` (regex stem, keeps `""` for dot-files): rename to `trayStem`, keep body.
    - `core/src/typst/language/project/projectSymbols.ts` `stemOf` (strips only `.typ`): rename to `typstStem`, keep body.
    - `core/src/library/conflicts/projectConflict.ts` `extensionOf` (returns `undefined`, dot-files count as extensions): rename to `conflictExtension`, keep body.
    - `vscode/src/writing/tree/projectFileCommands.ts` `baseName` (a `vscode.Uri` variant) is not touched unless `pnpm lint:modules` reports `shared-name` for it; then rename it `uriBaseName`.
