# Brief 7.1 — Encoding additions
Read only: research/7.md; reorganization.md §4 lines 708–721; `packages/core/src/encoding/*.ts`; `share/shareLink.ts` (`decodeKey`, `KEY`); `collab/invite/invite.ts` (`decodeKey`); `node scripts/docs/doc.mjs contracts/share-link` (key format).

Decided:
- `base64.ts`: add exported `bytesToBinary(bytes: Uint8Array): string` (the 0x8000-slice `String.fromCharCode` loop; the `// PLATFORM` comment moves onto it); `bytesToBase64` becomes `btoa(bytesToBinary(bytes))`, output byte-identical (test with 100,000 bytes and empty).
- `hex.ts`: add strict `hexToBytes(hex: string): Uint8Array`; throws `Error("Not hexadecimal (<n> characters)")` for odd length or any char outside `[0-9a-fA-F]`; empty gives empty; both cases accepted. Tests: round trip with `bytesToHex`, odd, `"zz"`, upper case, empty. The old private copy in `share/shareCipher.ts` accepted bad input but only ever got a `deriveSha256Hex` result: no caller changes behaviour (say so in a test name).
- New `bytes.ts` (byte values): `sameBytes(a, b)` (length check then element compare; both existing copies have this body; `Uint8Array` only), `fillRandom(bytes: Uint8Array<ArrayBuffer>): Uint8Array<ArrayBuffer>` over `globalThis.crypto.getRandomValues`, `randomHex(byteCount = 4, fill = fillRandom): string` (lower-case hex via `bytesToHex`). Move `joinBytes` into `bytes.ts`, delete `joinBytes.ts`, re-point its importers. Tests: sameBytes equal/length/byte/empty; randomHex length, charset, injected `fill`.
- `base64url.ts`: add `decodeKeyBytes(text: string, length: number): Uint8Array | undefined`: bytes only when `base64UrlToBytes` succeeds and has exactly `length` bytes; every failure returns `undefined`, never throws. The `// TRAP` comment of `shareLink.ts` moves verbatim to the `catch` (22 base64url chars hold 132 bits, a last char with stray low bits is not canonical and throws). `shareLink` has pre-check `KEY = /^[A-Za-z0-9_-]{22}$/`, `invite` none. Write a test table (valid 16-byte key, 21 and 23 chars, `+` `/`, `=` padding, stray low bits, inner whitespace, empty) against `decodeKeyBytes(text, 16)`: if every row is rejected without the regex, `shareLink` drops `KEY`; else `decodeKeyBytes` keeps pre-check `/^[A-Za-z0-9_-]*$/`. Parse results of share links and invites stay identical (D4); existing `__tests__/share` and `__tests__/collab` pass unmodified.
- Export all from `encoding/index.ts` and update its doc comment. Callers are 7.3's job.
