# Brief 11b.3 — the `Doi` brand

**Goal:** add `Doi`, `toDoi` and `isDoi` in `identifiers/doi.ts` and type the DOI producers with it.

**Read only:** `documents/plans/reorganization/research/11b.md`; `packages/core/src/import/identifiers/doi.ts` and `detectedIdentifier.ts`; `packages/core/src/libraryUi/protocol/messageGuards.ts` lines 15–25; `analysis/typing.md` line 386; `documents/code.md` Contracts is not needed.

**Decided:** `export type Doi = string & { readonly __brand: "Doi" }`; `isDoi(value: unknown): value is Doi` is true when `typeof value === "string"` and the `DOI_SHAPE` pattern of `doi.ts` matches; `toDoi(value: string): Doi | undefined` returns the value when `isDoi`, else undefined. `normalizeDoiCandidate` and `extractDoi` return `Doi | undefined` (same runtime values); `DetectedIds.doi` (and the identifier type that carries it) becomes `Doi`; `deriveDoiVariants(doi: Doi): Doi[]` and `encodeDoiPathSegment(doi: Doi)`. A caller that holds a plain `string` (record fields, registry responses) is left on `string` unless it already passes through `extractDoi`/`normalizeDoiCandidate`; where a conversion would be needed in more than 5 places for one parameter, keep that parameter `string` and say so in the log. The strict protocol check `isDoi` in `libraryUi/protocol/messageGuards.ts` matches a different pattern (`^10\.\d{4,9}/\S+$`): leave it as is (D2: not unified; S16 owns that parser) and note the difference in a comment on the new `isDoi`. Export `Doi`, `toDoi`, `isDoi` from `identifiers/index.ts`. No other brand (D3). No `as Doi` casts outside `toDoi`.

**Done when:** test first in `packages/core/__tests__/import/identifiers/` (a DOI with a multi-part prefix `10.1000.10/x`, a non-DOI string, `toDoi` of `"10.1234/abc"` and of `"abc"`); `pnpm gate core` passes; `grep -rn "as Doi" packages/core/src` shows only `doi.ts`; knip passes (every new export has a user).

**Do not touch:** `libraryUi`, `library/`, apps' types.
