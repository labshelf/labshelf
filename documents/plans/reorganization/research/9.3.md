# Brief 9.3 — readStable
Read only: research/9.md; reorganization.md lines 551–557; the files above.

Decided:
- New `collab/mirror/fileSystem/readStable.ts`: `export interface MirrorSample { size: number; mtimeMs: number; bytes: Uint8Array }` and `export async function readStable(sample: () => Promise<MirrorSample | undefined>, settleMs?: number): Promise<MirrorFileRead>`. One sample when `settleMs` is undefined; otherwise wait `settleMs`, sample again, return `{ state: "changing" }` unless size, mtimeMs and bytes (`sameBytes` from session 7) agree (two `undefined` agree, one does not); then `{ state: "present", bytes }` or `{ state: "missing" }`. Neutral: `setTimeout` only, no `Buffer`.
- `libraryMirrorFileSystem.ts` keeps only its port-based `sample` (maps `LocalStat` size/mtimeMs onto `MirrorSample`; read the real field names) and `read` calls `readStable(() => sample(relative), stableMs)`. `nodeMirrorFileSystem.ts` keeps only its `node:fs` `sample`; `readDisk` becomes `readStable(() => sample(file), settleMs)`. Each keeps its own `assertProjectDirReadable`/TRAP handling around the call. Delete both private `same`, the `Sample` types and the Buffer `equals`.
- Export `readStable` and `MirrorSample` from the folder `index.ts` (`collab/node` imports it).
- Behaviour unchanged. Tests first (`__tests__/collab/readStable.test.ts`, fake timers): no settle gives one sample; stable is `present`; size, mtime and byte change each give `changing`; vanishing between samples is `changing`; missing twice is `missing`. Existing mirror file-system tests pass unmodified.
