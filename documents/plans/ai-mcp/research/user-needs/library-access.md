# Retrieve the researcher's existing library

This is qualitative evidence, not a representative survey or approved feature list. The same need can support an embedded workflow or an external integration.

## Reuse owned papers

A Paperpile user wants agents to consult the existing PDF repository and add genuinely missing papers, avoiding repeated downloads and parallel folders. The author builds a small CLI for their own workflow; this is a user/developer report, not independent adoption data. The detailed anecdote in the post is labelled an AI summary.

Source: [Paperpile, 2026-09-01](https://forum.paperpile.com/t/letting-ai-assistants-see-the-pdfs-already-in-your-paperpile-library-small-cli-mit/12394).

A DEVONthink user reports maintaining copies for both storage and agent processing and wants direct retrieval plus saving results back. Other participants want to keep using their established external agent, combine repositories and consult personal notes.

Source: [DEVONthink discussion, 2026-04-29 onward](https://discourse.devontechnologies.com/t/what-would-you-do-with-an-mcp-server/86828).

Candidate: find what is already owned, read it without manual attachment, and distinguish a missing file from a retrieval or sync failure.

## Search meaning and personal reading

A Zotero user asks about methods across a collection and retrieving annotations by topic; the thread contains both actual users and tool promotions. Do not count its cross-post as separate demand.

Source: [Zotero user thread, 2025-07-03](https://www.reddit.com/r/zotero/comments/1lqjpl6/anyone_using_zotero_with_mcp_model_context/).

A frequent MCP user requests annotation tags alongside highlight text, colour and page. The thread includes feedback after using the resulting feature, making it stronger evidence of a practical workflow than a product announcement.

Source: [Zotero MCP #377, 2026-07-11](https://github.com/54yyyu/zotero-mcp/issues/377).

Candidate: search full text and personal annotations while preserving which words belong to the paper, the researcher and the model.

## Inspect visual scientific content

A user describes building and using a prototype that locates figures and renders only relevant PDF pages/regions. The problem is discussing figures, equations and tables with only extracted text or captions available.

Source: [Zotero MCP #391, 2026-07-19](https://github.com/54yyyu/zotero-mcp/issues/391).

Candidate: return the actual requested visual content with paper/page provenance. Image output to a model is separate from an interactive MCP App. The issue's numeric transport/model limits are environment-specific claims, not protocol requirements.

[Evidence lookup and review-table tasks](review-workflows.md) describe what researchers want to do with these inputs. [Usability](usability.md) covers why whole-library or whole-PDF context is unsuitable by default.
