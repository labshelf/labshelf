# Research: offline spelling and completion libraries

Run on Node 26 / macOS with the npm packages; not run in a browser or worker.

- **nspell 2.1.5** cannot load pt-BR (`RangeError: Too many properties to enumerate`); also fails on it and pt-PT. Rejected.
- **typo-js 1.4.0** loads pt in 5.3 s / ~937 MB heap, `suggest` 1.3 s. Rejected.
- **hunspell-asm 4.0.2** (MIT; Hunspell LGPL/MPL): real Hunspell in asm.js, ~780 KB browser build, no WASM CSP needed. pt-BR: dictionary load ~150 ms, ~59 MB RSS, `spell` ~2 µs/word, `suggest` up to ~150 ms for hard words. API: `spell`, `suggest`, `addWord`, `removeWord`, `addDictionary`. Unmaintained since 2022; fallback `hunspell-wasm` 0.3.0 (untested).
- **Dictionaries** (wooorm `dictionary-*` v4): `dictionary-en` (en-US, MIT AND BSD, ~192 KB gzip), `dictionary-pt` (Brazilian VERO, LGPL-3.0 OR MPL-2.0, ~1.38 MB gzip), `dictionary-pt-pt` (European). German is GPL only: download, never bundle. Files `index.aff`, `index.dic`; fetchable at `https://cdn.jsdelivr.net/npm/dictionary-<code>@<version>/index.{aff,dic}` (CORS `*`, immutable cache). Codes: bg, br, ca, ca-valencia, cs, cy, da, de, de-AT, de-CH, el, el-polyton, en, en-AU, en-CA, en-GB, en-ZA, eo, es (+ regional), et, eu, fa, fo, fr, fur, fy, ga, gd, gl, he, hr, hu, hy, hyw, ia, ie, is, it, ka, ko, la, lb, lt, ltg, lv, mk, mn, nb, nds, ne, nl, nn, oc, pl, pt, pt-PT, ro, ru, rw, sk, sl, sr, sr-Latn, sv, sv-FI, tk, tr, uk, vi.
- **Grammar**: Harper (rule-based, English only, ~8 MB gzip, ~300 MB RSS) — dropped by the user; no offline Portuguese grammar exists in JS.
- **Completion**: strip `.dic` flags into a sorted, deduplicated stem array (pt: 312k stems, built in ~94 ms); binary search + `startsWith` scan ~0.01 ms. Sort with plain `.sort()` (code units), never `localeCompare`. Stems miss inflections: expand only the matching stems on demand (`hunspell-reader` 10.4.1, MIT, untested) and add the document's own words.
- **babel → BCP-47**: babel's `locale/<lang>/babel-<tag>.ini` (`name.babel` aliases, `name.polyglossia`, `tag.bcp47`). brazilian/brazil/portuguese-br → pt-BR; portuguese → pt-PT; american/usenglish → en-US; british/ukenglish → en-GB; english → en-US; german/ngerman → de; austrian → de-AT; french → fr; spanish → es; mexican → es-MX. Polyglossia: `\setmainlanguage[variant=brazilian]{portuguese}` — language name first, variant refines.
