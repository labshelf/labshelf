## 10.1 — Store

- **Goal:** store Space notes as `spaces/<id>/notes/<slug>.qmd` and discussion threads as `spaces/<id>/discussions/<slug>.qmd`.
- **Read only:** `documents/plans/qmd-notes/research/spaces-collab.md` (Spaces on disk), `documents/contracts/spaces.md:7-17,80-90`, `packages/core/src/spaces/store/spaceStore.ts`, `packages/core/src/spaces/store/serialWrites.ts`, `packages/core/src/spaces/store/readSpace.ts`, `packages/core/src/qmd/projectNotes/index.ts` (slug and store shape to reuse).
- **Decided:**
  - One file per note and one per thread. A note file: items as in any `.qmd`; the first item starts with `# <title>`. A thread file: the first item is the topic (`# <title>` plus body, attribute `status="open"|"resolved"`); each message is one item with `author` and `created`, in file order.
  - Code in `packages/core/src/spaces/store/qmd/` (`spaceNotesStore.ts`, `spaceDiscussionsStore.ts`, `index.ts`); slugs reuse `noteSlug` from `qmd/projectNotes`. Writes go through `serialWrites` (serial per Space), re-read first, atomic, identical bytes in all apps.
  - Merge across devices is session 2's block merge (the Space scan already walks `spaces/<id>/**/*.qmd`); nothing here.
  - Sharing a Space is out of scope (per Q4, if answered otherwise, stop and report): files and local UI only, no share kind, no relay doc.
- **Done when:** tests: create note, create thread, add message keeps author/created, resolve sets `status`, concurrent adds to one thread keep both.
- **Do not touch:** `packages/core/src/qmd/items/`, `packages/core/src/qmd/merge/`, `packages/core/src/collab/`.

## 10.2 — Protocol and host

- **Goal:** the Space views read and edit notes and threads through Space protocol messages.
- **Read only:** `packages/core/src/spaces/protocol/messages.ts`, `packages/core/src/spaces/protocol/parseSpaceMutation.ts`, `packages/core/src/spaces/protocol/parseSpacesMessage.ts`, `packages/core/src/spaces/applySpaceMutation.ts`, `packages/core/src/spaces/serveSpaces.ts`, `packages/core/src/spaces/spacesHostPort.ts`.
- **Decided:** host→view `spaceNotes {spaceId, notes: {path, title, updated}[]}`, `spaceDiscussions {spaceId, threads: {path, title, status, messages, updated}[]}`, `spaceQmd {spaceId, path, items: {id, body, author, created}[]}`; view→host `createSpaceNote {spaceId, title}`, `createSpaceThread {spaceId, title, body}`, `addSpaceItem {spaceId, path, body}`, `editSpaceItem {spaceId, path, id, body}`, `removeSpaceItem {spaceId, path, id}`, `setThreadStatus {spaceId, path, status}`. Every `path` is validated to stay inside `notes/` or `discussions/` of that Space (reject `..`, absolute, non-`.qmd`).
- **Done when:** guard tests for each message, including path escapes; `serveSpaces` test for one add.
- **Do not touch:** apps.
