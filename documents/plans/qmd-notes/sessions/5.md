## 5.1 — VS Code webviews

- **Goal:** webview bundles that include the editor can load `@labshelf/core/math` as a separate file on first use.
- **Read only:** `documents/plans/qmd-notes/research/editor-ui.md` (Bundling and CSP), `packages/vscode/build/webviews.mjs:1-60` (`BUNDLES` :10-21, one esbuild call, esm, no splitting), `packages/vscode/build/host.mjs:15-35`, `packages/vscode/src/ui/list/listPanelHtml.ts:20-40` (CSP :28), `packages/core/src/reader/pdf-viewer/renderer/readerDocument.ts:15-35` (CSP :24).
- **Decided:**
  - Enable `splitting: true` with `format: "esm"` and `outdir` for the webview build so the dynamic `import("@labshelf/core/math")` becomes its own chunk; script tags load entries as `type="module"`; `localResourceRoots` and `script-src ${cspSource}` already cover the chunk folder; check it.
  - CSP stays without `'unsafe-inline'` for styles: the editor sets no markup `style=` (session 4). If a violation remains, fix it in core, not by relaxing the CSP; report it.
  - Do not add the editor to any bundle yet beyond a check that it builds; sessions 6–10 mount it.
- **Done when:** `pnpm --filter @labshelf/vscode build` passes; the output has a separate math chunk; bundle size of entries without math stays within 5% of before.
- **Do not touch:** core source other than the CSP line named above.
