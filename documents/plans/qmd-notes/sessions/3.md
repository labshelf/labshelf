## 3.2 — Schema

- **Goal:** `qmdSchema` in `packages/core/src/qmd/prosemirror/schema/`.
- **Read only:** `documents/contracts/qmd-items.md` (`#format`, `#outputs`), `packages/core/src/qmd/index.ts`, `packages/core/src/qmd/outputs/outputBlock.ts`, `packages/core/src/library/links/labshelfLink.ts:17-34`.
- **Decided:**
  - Nodes: `doc`, `paragraph`, `heading{level}`, `bullet_list`, `ordered_list{order}`, `list_item`, `task_item{checked}`, `math_inline{tex}` (atom), `math_display{tex, label}` (atom, label = `eq-…` or null), `code_cell{lang, options: string (the `#|` lines verbatim), code}`, `output{cell, source, engine, ran, raw}` (atom, raw = exact bytes), `image{src, alt}`, `citation{keys: string[], raw}` (inline atom), `raw_block{text}` (anything outside the subset, shown read-only in Source form), `hard_break`, `text`.
  - Marks: `em`, `strong`, `code`, `link{href}` (`labshelf:` hrefs are links like any other; the editor styles them).
  - Every node that can be written in more than one way stores its source spelling in an attr (`marker` for `*`/`-`/`+` and `_`/`*`, `fence` for backtick count) so serialization reproduces it.
  - Root of `prosemirror/` imports only `prosemirror-model`; no DOM. `toDOM` specs are allowed in the schema (they are data, not DOM calls).
- **Done when:** a unit test builds a document with every node and mark and checks `node.check()`.
- **Do not touch:** `packages/core/src/qmd/items/`.

## 3.3 — Body ↔ document conversion

- **Goal:** `bodyToDoc(body: string): Node` and `docToBody(doc: Node): string`, with `docToBody(bodyToDoc(b)) === b` for every item body LabShelf wrote.
- **Read only:** `documents/contracts/qmd-items.md`, `packages/core/src/qmd/prosemirror/schema/index.ts`, `packages/core/src/qmd/items/parseItemFile.ts`, `packages/core/src/qmd/outputs/outputBlock.ts`, `packages/core/__tests__/qmd/fixtures/` (list and read 3 fixtures), `packages/core/__tests__/qmd/items/` (test style).
- **Decided:**
  - Hand-written block parser over lines (the subset is small; no Markdown dependency), inline parser for emphasis, code, math, links, citations. Files: `parse/parseBlocks.ts`, `parse/parseInline.ts`, `serialize/serializeBlocks.ts`, `serialize/serializeInline.ts`, `index.ts` (≤8 files per folder).
  - Unrecognised constructs become `raw_block` or literal text, never dropped.
  - Blank-line runs and trailing whitespace are kept in node attrs (`gap` on blocks) to reach byte identity.
  - A document built by the editor (no source spellings) serializes in canonical form: `-` bullets, `*` emphasis, `**` strong, three-backtick fences, one blank line between blocks.
  - Collab (per Q1, if answered otherwise, stop and report): the shared doc holds a `Y.XmlFragment` bound with y-prosemirror; this session only guarantees `docToBody` is the disk serializer the mirror will call. No collab wiring here.
- **Done when:** byte-identical round trip on every session 1 fixture item body; canonical serialization tests for an editor-built doc; malformed input never loses text.
- **Do not touch:** `packages/core/src/qmd/items/`, `packages/core/src/collab/`.
