## 1.1 — Write the `qmd-items` contract

- **Goal:** Write `documents/contracts/qmd-items.md`, the single source of truth for the format every later session uses.
- **Read only:** `documents/contracts/library-format.md:243-265` (shape of an existing contract section, comments.json), `documents/contracts/sync.md:15-21`, `documents/plans/qmd-notes/research/editor-ui.md` (math, `labshelf:` links).
- **Decided:**
  - D1: the format is "LabShelf Markdown", a defined subset of Quarto Markdown. Code lives in core domain `packages/core/src/qmd/` (runtime-neutral root, `dom/` for the editor).
  - The subset: paragraphs of text with emphasis/strong/inline code; ATX headings `#`–`######`; bullet and ordered lists; task lists `- [ ]` / `- [x]`; inline math `$…$`; display math `$$…$$` optionally followed by ` {#eq-<label>}`; code cells ```` ```{python} ```` whose first lines may be `#| label: <label>` (and other `#|` options, kept verbatim); output blocks (below); images `![alt](path)`; `labshelf:` links (`[text](labshelf:…)`, grammar from `packages/core/src/library/paper/paperLink.ts:17-34`); citations `[@key]`, `[@a; @b]`. Anything else is kept verbatim as a raw block and never dropped.
  - D2: one file per case. Each item is a fenced div `::: {#<id> .labshelf-item anchor="…" author="…" created="…"}` … `:::`. Ids are `n-` + ULID (26 chars Crockford base32, time-sortable). Text outside any item is kept and shown as an item without anchor; nothing a user wrote is ever dropped. Unknown attributes on the fence are kept in order.
  - Anchor grammar (attribute `anchor`): absent or empty = none; `hl:<annotation id>` = a highlight in `data.json`; `p<page> box <x> <y> <w> <h>` = a text box, page 1-based, x/y/w/h page fractions 0..1 written with at most 4 decimals; `quote:<base64url JSON {quote,prefix,suffix}>` = project text quote anchor (same fields as comments.json anchor).
  - D3: a cell result follows its cell as `::: {.labshelf-output cell="<label>" source="<sha256 prefix of the cell code>" engine="…" ran="…"}` … `:::`. Source prefix = first 12 hex chars of SHA-256 of the cell code (UTF-8, `#|` lines excluded, trailing newline trimmed). A mismatch means out of date. `ran` is ISO-8601 UTC. `engine` is e.g. `python-3.12 sympy-1.13`.
  - `created` is ISO-8601 UTC; `author` is the display name string.
  - Malformed fence (unclosed `:::`, bad attributes): the text stays as text outside items, never lost.
  - Byte-identity: serialize(parse(file)) === file for any file LabShelf wrote; line endings and a missing final newline are preserved.
  - Section anchors in the contract: `#format`, `#items`, `#anchors`, `#outputs`, `#ids`, `#merge` (left as a stub sentence pointing to sync.md, filled in session 2).
- **Done when:** the contract exists, under 250 lines, present tense, every rule above stated once.
- **Do not touch:** any code; other contracts.

## 1.2 — Ids and anchors

- **Goal:** Generate item ids and parse/format anchors.
- **Read only:** `documents/contracts/qmd-items.md` (`#ids`, `#anchors`), `packages/core/src/reader/sidecar/paperSidecarStore.ts:20-30` (injected `newId` pattern), `packages/core/src/hash/index.ts`, `packages/core/src/hash/contentHash.ts`, `packages/core/src/collab/comments/` anchor type `commentAnchor.ts:15-21`.
- **Decided:**
  - Core has no ULID helper (only `crypto.randomUUID`); write `packages/core/src/qmd/ids/itemId.ts`: `newItemId(now = Date.now(), random = crypto.getRandomValues)` → `n-<ULID>`, plus `isItemId(s)`. No dependency (a ULID is ~25 lines). `globalThis.crypto` only, no `node:*`.
  - `packages/core/src/qmd/anchors/itemAnchor.ts`: `type ItemAnchor = {kind:"none"} | {kind:"highlight", annotationId} | {kind:"box", page, x, y, w, h} | {kind:"quote", quote, prefix, suffix}`; `parseAnchor(attr?: string): ItemAnchor | {kind:"unknown", raw}` (unknown kept verbatim), `formatAnchor(a)`.
  - Each folder gets an `index.ts`; headers per `scripts/checks/bannedWords.mjs` and the check-rules hook.
- **Done when:** tests in `packages/core/__tests__/qmd/ids/` and `anchors/` (format→parse round trip, monotonic ids within one ms, rejects of malformed boxes) pass with `pnpm --filter @labshelf/core test`.
- **Do not touch:** `packages/core/src/reader/`, `packages/core/src/collab/`.

## 1.3 — Item file parse/serialize

- **Goal:** `parseItemFile(text): ItemFile` and `serializeItemFile(file): string`, byte-identical on round trip.
- **Read only:** `documents/contracts/qmd-items.md` (whole), `packages/core/src/qmd/ids/index.ts`, `packages/core/src/qmd/anchors/index.ts`, `packages/core/src/hash/contentHash.ts`, `packages/core/src/library/paper/paperLink.ts:17-34`.
- **Decided:**
  - Shape: `ItemFile = { segments: Segment[] }`, `Segment = {kind:"loose", text} | {kind:"item", id, anchor, author?, created?, attrs: [name, value][] (in source order, includes unknown), fence: string (exact opening line), body: string (exact bytes between fences), close: string}`. Items are not parsed into blocks here; the block-level model is session 3's job.
  - `packages/core/src/qmd/items/`: `parseItemFile.ts`, `serializeItemFile.ts`, `itemFence.ts` (attribute parse/format of `{#id .class key="v"}`), `itemEdit.ts` (`addItem`, `replaceItemBody`, `removeItem` producing a new `ItemFile`; new fences written in canonical attribute order `#id .labshelf-item anchor author created`).
  - `packages/core/src/qmd/outputs/`: `outputBlock.ts` (`findOutputs(body)` → `{cell, source, engine, ran, start, end}[]`, `formatOutput(...)`), `cellSource.ts` (`cellSourceHash(code)` = first 12 hex of SHA-256 per contract; reuse `hash/contentHash.ts` if it exposes SHA-256, else `crypto.subtle`).
  - Nested `:::` inside an item (outputs) are counted by depth; an unclosed fence makes the whole tail `loose`.
  - `packages/core/src/qmd/index.ts` exports the public API; add `export * from './qmd'` style line in `packages/core/src/index.ts` only if other domains are exported that way there.
  - Fixtures in `packages/core/__tests__/qmd/fixtures/` (notes with math, a cell + output, task list, loose text, unknown attrs, CRLF, no final newline, unclosed fence). Session 3 reuses them.
- **Done when:** A1 tests pass: round trip byte-identical on every fixture; loose text survives; unknown attributes survive; malformed fence never loses text. `pnpm --filter @labshelf/core typecheck` passes.
- **Do not touch:** anything outside `packages/core/src/qmd/` and its tests, except the one export line.
