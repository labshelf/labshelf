## 9.1 — Project notes store

- **Goal:** `ProjectNotesStore` lists, creates, reads and edits the `.qmd` notes of a project.
- **Read only:** `packages/core/src/qmd/paperNotes/index.ts` (store shape to mirror), `packages/core/src/qmd/items/itemEdit.ts`, `packages/core/src/qmd/index.ts`, `packages/core/src/writing/project/projectFile.ts:1-30` (`PROJECT_FORMATS` :11), `packages/core/src/collab/comments/commentsFileStore.ts` (injected file access pattern), `documents/contracts/qmd-items.md` (`#items`, `#merge`).
- **Decided:**
  - Project notes are `<project>/notes/<slug>.qmd`; slug = lowercase ASCII words of the title joined by `-`, suffix `-2`, `-3` on collision. The first item's body starts with `# <title>`. `PROJECT_FORMATS` stays `latex`/`typst` (notes are not a manuscript format).
  - Files under `packages/core/src/qmd/projectNotes/`: `projectNotesStore.ts` (`list(projectId)`, `create(projectId, title)`, `read(projectId, path)`, `addItem`, `editItem`, `removeItem`), `noteSlug.ts`, `index.ts`. File IO through an injected `IProjectNoteFiles {list, read, write}` port; each write re-reads, applies, writes atomically, serial per file. A missing file reads as empty. Every write failure is logged through `ILogger`.
  - Merge across devices is session 2's block merge (`.qmd` is already in the mergeable set); nothing here.
- **Done when:** tests: create with slug collision, list ignores non-`.qmd`, two concurrent `addItem` on one file keep both.
- **Do not touch:** `packages/core/src/qmd/items/`, `packages/core/src/qmd/merge/`, apps.

## 9.2 — Checklist from project notes

- **Goal:** D9: the checklist and problems are views derived from project `.qmd` files; `- [ ]` / `- [x]` in a project note is a checklist item, and ticking it in the Checklist view edits the note.
- **Read only:** `documents/plans/qmd-notes/research/comments-checklist.md` (Checklist), `packages/core/src/writing/checklist/buildChecklist.ts:8-37,59-110` (`ChecklistInput`, `ChecklistItem`, `toItems` :59, `byKind` :75, `bySection` :98), `packages/core/src/writing/checklist/readChecklistSignals.ts:64-84`, `packages/core/src/writing/checklist/updateChecklist.ts`, `packages/core/src/writing/checklist/sidebar/checklistRows.ts`, `packages/core/src/qmd/projectNotes/index.ts`.
- **Decided:**
  - New input field `noteTasks: NoteTask[]` with `NoteTask = {file, itemId, line, text, done}` (line = zero-based line inside the file); new union member `{kind: "noteTask", …}`, grouped as `todo` in `byKind`, placed under the note's title in `bySection`.
  - Code in a subfolder `packages/core/src/writing/checklist/notes/` (`scanNoteTasks.ts`: reads task-list lines from item bodies, skipping code cells and output blocks; `toggleNoteTask.ts`: flips `[ ]`↔`[x]` on that line through `ProjectNotesStore.editItem`, after checking the line text still matches, else reports "changed on disk" and rereads). The checklist folder stays at 8 source files or fewer.
  - `readChecklistSignals` fills `noteTasks` from `ProjectNotesStore.list`. Manual `.labshelf/checklist.json` items stay as they are.
- **Done when:** tests: scan finds open and done tasks, ignores tasks in code cells; toggle edits only that line; toggle on a changed line refuses and leaves the file untouched.
- **Do not touch:** `packages/core/src/qmd/items/`, `checklistFile.ts` format.

## 9.3 — Send to

- **Goal:** D10: "Send to…" on a selection (PDF passage, figure crop, equation, item) appends an item with a `labshelf:` back-link to a chosen `.qmd` target, remembering recent targets per device.
- **Read only:** `packages/core/src/library/paper/paperLink.ts:17-34` (grammar, `format`), `packages/core/src/qmd/projectNotes/index.ts`, `packages/core/src/qmd/paperNotes/index.ts`, `packages/core/src/qmd/items/itemEdit.ts`, `packages/core/src/qmd/ids/index.ts`, `documents/contracts/qmd-items.md` (`#format`).
- **Decided:**
  - Code in `packages/core/src/qmd/sendTo/`: `sendTarget.ts` (`SendTarget = {kind: "projectNote", projectId, path} | {kind: "spaceNote", spaceId, path} | {kind: "discussion", spaceId, path}`), `sendPayload.ts` (`SendPayload = {kind: "quote", key, page, text} | {kind: "figure", key, page, image: Uint8Array, mime} | {kind: "equation", key, page, latex} | {kind: "item", sourcePath, itemId, body}`), `sendItemBody.ts` (payload → LabShelf Markdown), `sendTo.ts` (appends via an injected `ISendTargetWriter`, one per target kind), `recentTargets.ts`, `index.ts`.
  - Body: quote → `> <text>` then `[<key>, p. <page>](labshelf:<key>#p<page>)`; equation → `$$ … $$` plus the same link; figure → the crop is written as a blob `<target folder>/assets/<item id>.png` and the body is `![](assets/<item id>.png)` plus the link; item → its body plus a link to the source item.
  - Recents: last 8 targets, most recent first, stored device-locally through an injected `IKeyValueStore`-style port (VS Code `globalState`, browser `chrome.storage.local`), never in the library.
  - Space targets write through session 10's store; until session 10 lands, `spaceNote`/`discussion` writers are not registered and the menu lists projects only.
  - The project checklist note is an ordinary project note: no separate kind.
- **Done when:** tests: body for each payload kind; append to a missing project note creates it; recents order and cap; a figure write failure leaves the note untouched and logs.
- **Do not touch:** `packages/core/src/library/paper/paperLink.ts`, apps.
