## 4.2 — Editor core

- **Goal:** `mountQmdEditor(root, {body, onChange(body), onRunCell(label, code), readOnly?, collab?}) → {setBody, focus, destroy}`.
- **Read only:** `documents/plans/qmd-notes/research/editor-ui.md`, `packages/core/src/qmd/prosemirror/index.ts`, `packages/core/src/qmd/prosemirror/schema/index.ts`, `packages/core/src/ui/dom/index.ts`, one existing component folder under `packages/core/src/<domain>/dom/` for shape (index.ts + .ts + self-contained .css).
- **Decided:**
  - D5: rich editor on ProseMirror in `packages/core/src/qmd/dom/editor/`; conversion via `bodyToDoc`/`docToBody`.
  - `onChange` fires debounced (300 ms) with `docToBody(doc)`; it is the only way content leaves the editor.
  - Input rules: `# ` heading, `- ` bullet, `1. ` ordered, `[ ] ` task, `$…$` inline math, `$$` display math, `\`\`\`python` code cell.
  - Source mode: a plain `<textarea>` with the item body; switching back parses it. Toggle state is per editor, not persisted.
  - Collab (per Q1, if answered otherwise, stop and report): `collab?: {fragment: Y.XmlFragment, awareness}` plugs `ySyncPlugin`, `yCursorPlugin`, `yUndoPlugin` from y-prosemirror; when present, history plugin is off. Wiring to shares is not in this plan's sessions beyond this option.
  - CSP: list/library/details webviews forbid inline styles (`style-src ${cspSource}`). ProseMirror view writes `style=` only for some decorations; use classes. Keep any unavoidable inline style out of node views (see 4.3).
- **Done when:** jsdom tests: mount, type text, `onChange` gives the expected body; toggle Source → edit → Visual keeps the change.
- **Do not touch:** `packages/core/src/qmd/prosemirror/`.

## 4.3 — Node views

- **Goal:** node views for `math_inline`, `math_display`, `code_cell`, `output`, `task_item`, link mark, `citation`.
- **Read only:** `documents/plans/qmd-notes/research/editor-ui.md` (Reuse, Risks), `packages/core/src/latex/hover/renderMathSvg.ts:1-40`, `packages/core/src/qmd/outputs/cellSource.ts`, `packages/core/src/qmd/dom/editor/index.ts`, `packages/core/src/ui/icons/icon.ts`, `packages/core/src/ui/icons/glyphs.ts`.
- **Decided:**
  - Math: render with `renderMathSvg` loaded lazily through `await import("@labshelf/core/math")`. TRAP: `@labshelf/core/math` is ~2.5 MB CJS with side effects; never import it statically or from the core root. Show the TeX source in a small inline input while the node is selected; parse error shows the TeX with an error class.
  - MathJax SVG carries `style=` attributes: strip `style` from the SVG root and nested nodes and map the vertical-align value to a class or a CSS custom property set via `CSSStyleDeclaration` (CSSOM is allowed under CSP; markup `style=` is not). Record the choice in a `// PLATFORM:` comment.
  - Code cell: monospace editable code, a Run button (core icon) that calls `onRunCell(label, code)`; the button is hidden when `onRunCell` is absent (hosts without a runner still show cells).
  - Output: renders text output and LaTeX output (math via the same lazy loader); marked out of date when `cellSourceHash(cell code) !== output.source`.
  - Task item: a checkbox toggles `checked` through a transaction.
  - `labshelf:` link: styled as an internal link with a core icon; click calls an injected `onOpenLink(href)`.
  - Citation: shows `[@key]` keys as a chip; no lookup here.
  - Icons from the core icon set only; add names to `glyphs.ts` if missing.
- **Done when:** jsdom tests for task toggle and out-of-date marking; math node view tested with a stubbed loader.
- **Do not touch:** `packages/core/src/latex/hover/`.
