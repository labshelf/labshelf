## 12.1 — Port and write-back

- **Goal:** a runtime-neutral port and the function that turns a run result into an output block inside the note.
- **Read only:** `documents/contracts/qmd-items.md` (`#outputs`), `packages/core/src/qmd/outputs/outputBlock.ts`, `packages/core/src/qmd/outputs/cellSource.ts`, `packages/core/src/qmd/items/itemEdit.ts`, `packages/core/src/qmd/paperNotes/index.ts`, `packages/core/src/qmd/projectNotes/index.ts`.
- **Decided:**
  - D11: cells run through a core port `ICellRunner`; cancel kills the process.
  - `packages/core/src/qmd/compute/cellRunner.ts`: `interface ICellRunner { run(code: string, opts: {cwd: string; signal: AbortSignal; timeoutMs: number}): Promise<CellResult> }`, `CellResult = {status: "ok" | "error" | "timeout" | "cancelled" | "missing-python", latex?: string, text?: string, error?: string, durationMs: number}`.
  - `packages/core/src/qmd/compute/writeCellOutput.ts`: given an item body, a cell label and a result, inserts or replaces the `::: {.labshelf-output cell="<label>" source="<hash>" engine="…" ran="…"}` block right after that cell (D3; `source` = first 12 hex chars of SHA-256 of the cell code, UTF-8, `#|` lines excluded, trailing newline trimmed; `ran` ISO-8601 UTC; `engine` e.g. `python-3.12 sympy-1.13`). Body of the block: `$$ <latex> $$` when `latex` is present, else the text in a plain fenced block; an error writes the error text with attribute `status="error"`. `cancelled` and `missing-python` write nothing. Uses `formatOutput` and the qmd serializer; never edits outside that item.
  - A cell without `#| label:` gets `#| label: cell-<n>` written on first run (n = position in the item) so the output can reference it.
  - Default timeout 60 s, passed by the host.
- **Done when:** tests: first run inserts, rerun replaces, error result, label added on first run, other items byte-identical.
- **Do not touch:** `packages/core/src/qmd/items/`, `packages/core/src/qmd/outputs/` (import only).

## 12.2 — `runCancellable` timeout and kill

- **Goal:** a stuck process ends: timeout, then SIGTERM to the group, then SIGKILL after a grace period; stdout and stderr separable.
- **Read only:** `documents/plans/qmd-notes/research/helper.md` (Running processes), `packages/core/src/latex/build/node/runCancellable.ts`, its existing tests under `packages/core/__tests__/latex/build/node/`, `packages/core/src/helper/node/build/buildHandlers.ts:97-122`.
- **Decided:** options gain `timeoutMs?`, `killGraceMs?` (default 2000), `separateStreams?` (result then has `stdout`, `stderr` tails); defaults keep build behaviour byte for byte. Timeout rejects with `ProcessTimedOut` beside `BuildCancelled`. Windows keeps `taskkill /T /F`. Log escalation through `ILogger`.
- **Done when:** tests: timeout kills a sleeping child, a SIGTERM-ignoring child gets SIGKILL, existing tests pass.
- **Do not touch:** build callers.

## 12.3 — Node runner and driver

- **Goal:** `NodeCellRunner` implements `ICellRunner` with the managed Python and a bundled driver.
- **Read only:** `packages/core/src/qmd/compute/cellRunner.ts`, `packages/core/src/qmd/compute/node/managed/index.ts`, `packages/core/src/latex/build/node/runCancellable.ts`, `packages/core/src/latex/toolchain/node/managedTex/sharedTexProvider.ts:1-29`, `packages/core/package.json` (files/exports for the driver asset).
- **Decided:** `packages/core/src/qmd/compute/node/nodeCellRunner.ts` and `cellDriver.py` (asset shipped with core; under 40 lines): takes the path of a temp file holding the cell code as its argument (`runCancellable` ignores stdin); the runner writes the file in the OS temp dir and deletes it after the run. The driver `exec`s all statements but the last, `eval`s the last if it is an expression, and prints one JSON line `{latex, text}` using `sympy.latex(result)` for SymPy objects and `str` otherwise; exceptions print `{error}` with the traceback's last line. Status `missing-python` when the provider reports `missing`. Python stderr goes to the log, not into the note.
- **Done when:** tests (skipped when no Python on the test machine, with a logged reason): `x**2` differentiates to `2 x`; syntax error; `while True: pass` times out; a fake provider yields `missing-python`.
- **Do not touch:** `node/managed/`.
