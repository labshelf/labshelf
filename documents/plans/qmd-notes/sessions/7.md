## 7.5 — Empty-space geometry

- **Goal:** pure functions that place and snap a text box against text rectangles of a page.
- **Read only:** `packages/core/src/reader/dom/highlights/derivePageFrame.ts`, `packages/core/src/reader/dom/highlights/textRects.ts`, `packages/core/src/reader/dom/hover/textGeometry.ts`, `documents/plans/qmd-notes/research/reader.md` (Text layer).
- **Decided:** runtime-neutral, in `packages/core/src/reader/geometry/textBoxPlacement.ts` with `index.ts`; inputs in page fractions: text rects `{x,y,w,h}[]`, a click point or a drag rect. `fitEmptyBox(point, rects)`: the largest rectangle around the point that overlaps no text rect, capped at 0.4 page width and 0.25 height, at least 0.05×0.03, else null. `snapBox(rect, rects)`: edges within 0.01 of a text rect edge or the page margin snap to it; a rect overlapping text is shrunk off the text on its smallest-overlap side. Fractions rounded to 4 decimals (contract). Text rects come only from the live DOM `.textLayer` (no stored geometry exists).
- **Done when:** unit tests: empty column, between paragraphs, over text (shrinks), page margin snap, too-small area returns null.
- **Do not touch:** DOM code.

## 7.6 — Text-box tool and page layer

- **Goal:** D7: a text box is a paper-note item with anchor `p<page> box <x> <y> <w> <h>` in page fractions, drawn over the page, always visible, never changing the PDF; long content is clipped and expands on click.
- **Read only:** `packages/core/src/reader/dom/highlights/pageHighlights.ts:20-60`, `packages/core/src/reader/dom/highlights/derivePageFrame.ts`, `packages/core/src/reader/dom/highlights/textRects.ts`, `packages/core/src/reader/dom/styles/reader.css:240-270`, `packages/core/src/reader/geometry/index.ts`, `packages/core/src/qmd/dom/editor/index.ts`.
- **Decided:**
  - Creation mode: a toolbar toggle; in it, click = `fitEmptyBox`, drag = `snapBox`; Escape leaves the mode; then `addNote {anchor: formatAnchor({kind:"box",…}), body: ""}` and the box opens in edit state.
  - Layer `.rd-note-layer` per page, built like `.rd-hl-layer`: rebuilt on pdf.js `textlayerrendered` (PLATFORM: pdf.js drops page children on re-render), positions in percent so zoom needs no recompute; the layer has `pointer-events: none`, boxes `pointer-events: auto`; inserted above the text layer so boxes are clickable but empty space selects text. Unrendered pages have no layer.
  - Box content renders read-only through the editor (`readOnly: true`); clipped to the box with a token-based fade; click expands to show all content and edit, outside click or Escape collapses. Move and resize handles send `moveNote {id, anchor}` with the snapped box.
  - Positions must not use markup `style=`; the reader webview allows inline styles, but set geometry via CSSOM like `pageHighlights.ts` does.
- **Done when:** typecheck; A5 by hand in VS Code and the browser reader (`documents/apps/verify.md#rules`).
- **Do not touch:** `packages/core/src/reader/geometry/` (except bugs agreed with 7.5).
