## 13.1 — Grammar, scanner, state

- **Goal:** find origin comments in a manuscript and compute each one's state.
- **Read only:** `documents/plans/qmd-notes/research/editor-ui.md` (Reuse: LaTeX scan, `writing/insert`), `packages/core/src/writing/latex/source/scan/scanLatexSource.ts`, `packages/core/src/writing/latex/source/facts.ts:1-70`, `packages/core/src/qmd/items/index.ts`, `packages/core/src/qmd/outputs/cellSource.ts`, `packages/core/src/hash/contentHash.ts`.
- **Decided:**
  - D12: an inserted equation ends with `% labshelf: <note path>#<eq label> @<hash>` (Typst: `// labshelf: <note path>#<eq label> @<hash>`). `<note path>` is POSIX, relative to the project folder for project notes, `paper:<paper id>/notes.qmd` for paper notes. `<eq label>` is the `{#eq-…}` label, or the output's `cell` label for an output. `<hash>` = first 12 hex chars of SHA-256 of the inserted LaTeX (the text between `\begin{equation}` and `\label{…}`, trimmed; same hash function as `cellSourceHash`).
  - LaTeX insert shape: `\begin{equation}<latex>\label{<eq label>}\end{equation} % labshelf: …` on one block, the comment on the `\end{equation}` line. Typst: `$ <typst math> $ <<eq label>> // labshelf: …` (LaTeX→Typst math only where `writing/insert` already converts; otherwise Typst insert is offered for outputs with a `text` form only, and the picker says so).
  - Files in `packages/core/src/writing/noteLinks/`: `originComment.ts` (parse/format), `scanOrigins.ts` (manuscript text → `{line, notePath, label, hash, insertedRange}[]`), `originState.ts` (`fresh` = manuscript hash and note hash equal `@hash`; `stale` = only the note changed; `diverged` = only the manuscript changed; `both`; `missing` = note or label gone), `index.ts`. Note text is read through an injected reader; scanning runs on open and save, never per keystroke.
- **Done when:** tests: parse/format round trip for both languages; each state on fixtures; a label removed from the note gives `missing`; a malformed comment is ignored, not an error.
- **Do not touch:** `packages/core/src/writing/latex/source/` (import only), `packages/core/src/qmd/`.

## 13.2 — Insert sources and text

- **Goal:** "Insert from note" lists equations and outputs of the project's notes and the cited papers' notes, and builds the insert text and update edit.
- **Read only:** `packages/core/src/writing/noteLinks/index.ts`, `packages/core/src/qmd/projectNotes/index.ts`, `packages/core/src/qmd/paperNotes/index.ts`, `packages/core/src/qmd/outputs/outputBlock.ts`, `packages/core/src/writing/backlinks/index.ts` (cited keys → papers), `packages/core/src/writing/insert/` (index and one LaTeX builder).
- **Decided:** `listNoteInsertables(project)` → `{notePath, label, latex, source: "equation" | "output", title}[]` from `$$ … $$ {#eq-…}` and from outputs with `latex`; out-of-date outputs (D3 hash mismatch) are listed with a mark and are not insertable until rerun. `buildInsert(item, language)` and `buildUpdate(origin, item)` (replaces only the inserted range and the hash; refuses for `diverged` and `both`). `diffOrigin(origin, item)` returns the two LaTeX texts for a side-by-side view.
  - Figures and numbers reuse `labshelf.yaml` `figures:` and `values:`: a cell that writes `values/<name>.json` or a figure file listed under `figures:` is picked up by the existing machinery. Nothing new here beyond listing them in the picker under "Figures" and "Values" with their existing insert snippets.
- **Done when:** tests: list from a fixture project with one note and one cited paper note; insert text for LaTeX; update refused on diverged.
- **Do not touch:** `labshelf.yaml` readers (import only).
