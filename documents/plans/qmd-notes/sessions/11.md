## 11.1 — Managed Python in core

- **Goal:** `sharedPythonProvider` reports status and installs python-build-standalone plus SymPy and mpmath wheels under the shared tools lock.
- **Read only:** `documents/plans/qmd-notes/research/helper.md` (Contracts, Managed TeX), `packages/core/src/latex/toolchain/tinyTex.ts:6-30`, `packages/core/src/latex/toolchain/node/managedTex/installTinyTex.ts:44-68`, `packages/core/src/latex/toolchain/node/managedTex/toolsDirLock.ts:90-110`, `packages/core/src/latex/toolchain/node/managedTex/managedTexProvider.ts`, `packages/core/src/latex/toolchain/node/managedTex/sharedTexProvider.ts:1-29`, `packages/core/src/latex/toolchain/node/downloadVerified.ts`.
- **Decided:**
  - D11: Python + SymPy is a managed tool under `<shared root>/python/`, pinned by version and SHA-256 like TeX. No Pyodide, nothing bundled in the extension.
  - Pin `packages/core/src/qmd/compute/pythonPin.ts` (runtime-neutral data): python-build-standalone release tag and Python version, one `{url, sha256}` per `darwin-arm64`, `darwin-x64`, `linux-x64`, `linux-arm64`, `win32-x64` (`install_only` archives); `sympy` and `mpmath` pure-Python wheels `{version, url, sha256}`.
  - `packages/core/src/qmd/compute/node/managed/`: `pythonLayout.ts` (installed = `bin/<arch>/python[.exe]` exists; `site-packages` inside), `installPython.ts` (download each archive with `downloadVerified`, stage in `stagingDir`, extract with `singleTopDir`, install wheels by unzipping into `site-packages` (a wheel is a zip; no pip run), `clearQuarantine` on macOS, swap in), `managedPythonProvider.ts` (status/install under `withToolLock(root, "install", logger, …)`), `sharedPythonProvider.ts` (factory, root = `sharedToolsRoot()/"python"`), `index.ts`. Reuse `sharedToolsRoot`, `withToolLock`, `stagingDir`, `singleTopDir`, `clearQuarantine`, `downloadVerified` by import, never copy.
  - Status: `{state: "missing"} | {state: "installed", version, sympy}`. A system Python is not used (pinned SymPy is the contract for reproducible outputs).
  - Progress and failures go through `ILogger`; a hash mismatch aborts before anything is written.
- **Done when:** tests: install from local fixture archives into a temp root; hash mismatch leaves no folder; second install under lock waits and rechecks; status reads unlocked.
- **Do not touch:** `packages/core/src/latex/toolchain/` (import only).
