## 8.1 — DB, parser, incremental build

- **Read only:** the shared sources above; `node_modules/oxc-parser` README or `index.d.ts` (`parseSync`, `module.staticImports`, `staticExports`, `Visitor`).
- **Decided:**
  - `scripts/ctx/db.mjs`: `openDb(path)` with `node:sqlite` `DatabaseSync`; tables `files(path PK, hash, header)`, `decls(path, name, kind, start, end, exported)`, `imports(path, specifier, names, resolved)`, `calls(path, line, callee)`; `schema_version` pragma; recreate on mismatch.
  - `scripts/ctx/parse.mjs`: `parseFile(path, source)` → `{header, decls, imports, exports, calls}`; header = leading `//` comment block only; decls are top-level with 1-based line ranges; re-exports (`export { x } from`) recorded as imports with names.
  - `scripts/ctx/build.mjs`: `buildIndex(root, db)` over `git ls-files` `.ts/.tsx/.mjs` in `packages/` and `scripts/`; sha1 of content; reparse only changed files, delete rows of removed files, one transaction; exports `indexFile(root, db, path)` for the hook.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/ctx/__tests__/build.test.mjs` passes: rows for the mini repo; second build reparses nothing; editing `b.ts` reparses only it; deleting a file drops its rows.
- **Do not touch:** `.claude/`, `scripts/plans/`.

## 8.2 — Resolver and `ctx` CLI

- **Read only:** the shared sources; `scripts/ctx/db.mjs`, `parse.mjs`, `build.mjs` (8.1); `research/telemetry-events.md` (`index_query`).
- **Decided:**
  - `scripts/ctx/resolve.mjs`: `oxc-resolver` with `extensionAlias {".js": [".ts", ".tsx", ".js"]}`; `@labshelf/core` → `packages/core/src/index.ts`. `build.mjs` fills `imports.resolved` (repo-relative or null).
  - `scripts/ctx/ctx.mjs def <symbol>` → `path:start-end kind` per declaration; `refs <symbol>` → importing files (following re-exports through `index.ts` files) and call sites as `path:line`; `file <path>` → header, decls, imports; `build` → incremental build with a one-line count. Output capped at 50 lines and ~8k tokens with a `… N more` line; each query emits `index_query` with `query_kind`, `results`, `chars`.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/ctx/__tests__/ctx.test.mjs` passes: `def foo` → `a.ts` lines; `refs foo` lists `b.ts` (via `./a.js`) and `c.tsx` (via `@labshelf/core` re-export) with call lines; cap respected.
- **Do not touch:** `.claude/`, `scripts/plans/`.

## 8.3 — Reindex hook and `plan size`

- **Read only:** plan.md D10; `scripts/ctx/build.mjs`, `ctx.mjs` (exports); `research/conventions.md` § Hooks; `scripts/plans/plan.mjs`.
- **Decided:**
  - `.claude/hooks/ctx-reindex.mjs` (PostToolUse `Edit|Write|MultiEdit`): when the DB exists and the edited path is indexable, `indexFile` it; any error or missing DB → exit 0 silently; target under 300 ms. Register after the test passes (timeout 5 s).
  - `plan size <paths…>` (`planSize.mjs`): prints files, packages, distinct caller files (via `refs` of exported decls of those files) and risk paths (path contains `documents/contracts`, `sync`, `storage`, `formats` or `manifest`), then `suggested: N<k>`: N0 = 1 file, ≤ 3 callers, no risk; N1 = ≤ 3 files, one package, no risk; N2 = ≤ 15 files and ≤ 2 packages, or any risk path; N3 = beyond that. The orchestrator confirms (D10).
- **Done when:** `node scripts/agents/run.mjs test tooling -- .claude/hooks/__tests__/ctx-reindex.test.mjs scripts/plans/__tests__/planSize.test.mjs` passes (edit updates the file's rows; no DB → silent exit 0; size thresholds on the mini repo).
- **Do not touch:** `scripts/ctx/parse.mjs` contract, other hooks.
