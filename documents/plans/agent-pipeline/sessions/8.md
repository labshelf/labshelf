## 8.2 — Refresh hook, runner build, guard allowlist

- **Read only:** plan.md D2, D12; `research/conventions.md` § Hooks; `scripts/code/lib.mjs` (lock), `facts.mjs` (`build`), `installHooks.mjs` (detached build); `.claude/hooks/spec-guard.mjs` (Bash allowlist); `scripts/plans/runPlan.mjs` (pre-session step).
- **Decided:**
  - `.claude/hooks/facts-refresh.mjs` (PostToolUse `Edit|Write|MultiEdit`): when the DB exists and the path is under `packages/*/src` or `packages/*/__tests__` (`.ts(x)`): write `.code-facts/dirty`, spawn a detached `facts build --quiet` unless the lock is held. `facts build` clears `dirty` at start and reruns once if it reappeared. No DB, other path or error → silent exit 0; returns in < 100 ms. Register after the test (timeout 5 s).
  - `runPlan.mjs`: before each session, when `scripts/code/facts.mjs` exists, run `node scripts/code/facts.mjs build --quiet` (failure only warns), replacing any `scripts/ctx` line.
  - `spec-guard.mjs`: the index allowlist entry is `node scripts/code/facts.mjs def|fn|sig|similar|find|callers|uses|tests …` or `pnpm -s facts …`, quota 10, replacing any `scripts/ctx` entry.
- **Done when:** `node scripts/agents/run.mjs test tooling -- .claude/hooks/__tests__/facts-refresh.test.mjs .claude/hooks/__tests__/spec-guard.test.mjs` passes (Edit leaves `dirty`, next build updates `b.ts` rows; no DB → silent; no 2nd spawn during a build; implementer may run `facts def`); `rg -n "scripts/ctx|ctx\.mjs" scripts .claude/hooks` is empty.
- **Do not touch:** the `extract.mjs` schema, other hooks.
