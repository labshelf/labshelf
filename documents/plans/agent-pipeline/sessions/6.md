## 6.1 — `plan stubs`, `plan tests`, `plan red`, `plan start`

- **Read only:** plan.md D6, D7; `research/schemas.md` § spec/v1 (`seams`, `tests`); `scripts/plans/plan.mjs`, `planFiles.mjs`; `scripts/agents/run.mjs` (summary parsers).
- **Decided:**
  - `plan stubs <session> <id>` (`planStubs.mjs`): per seam, `export function <name>(<params>) { throw new Error("not implemented: <id>") }` (async/class forms keep their keyword); creates the file or appends when the symbol is missing; never touches an existing symbol.
  - `plan tests <session> <id>` (`planTests.mjs`): one skeleton per acceptance id into the hidden tests path: jest `.test.ts` for `packages/`, `node:test` `.test.mjs` for `scripts/` and `.claude/`; test names `A<n> <check>`; body imports the seams and fails with a TODO assertion. Refuses to overwrite.
  - `plan red <session> <id>` (`planRed.mjs`, D7): record every path it will touch (with original content or absence) in `.git/labshelf-red.json` first; apply stubs and copy hidden tests in place; run `tests.command` through `run.mjs` without `--spec` (not counted); pass only if every test failed and every failure message contains `not implemented`; a compile, import or syntax error, or any passing test, rejects with the offending test names. Always restore all recorded paths and delete the record. `plan red --restore` restores from the record after a crash. Export the jest and TAP parsers from `run.mjs` to get per-test status and message.
  - `plan start <session> <id>` (`planStart.mjs`): copy hidden tests into place, add stubs for seams whose symbol is missing, emit `package_started` with `level` and `model`.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/plans/__tests__/planRed.test.mjs scripts/plans/__tests__/planStubs.test.mjs scripts/plans/__tests__/planStart.test.mjs` passes: red accepts a `node:test` fixture failing on `not implemented`, rejects one with an import error, and `git status --porcelain` is identical before and after both; `--restore` after a simulated crash restores; start leaves tests and stubs in place.
- **Do not touch:** `planLint.mjs`, `runPlan.mjs`, `.claude/`.

## 6.2 — `plan close`

- **Read only:** plan.md D8; `research/schemas.md` (session/v1, spec/v1, report/v1); `research/conventions.md` (state paths); `research/telemetry-events.md` (`commit`, `session_closed`); `scripts/plans/planFiles.mjs`.
- **Decided:** `plan close <session>` (`planClose.mjs`), in this order:
  1. Changed or new files (`git status --porcelain`) outside the session `owns` → fail, nothing committed.
  2. Gate once: `pnpm gate --no-lint`, or `pnpm gate` when `milestone: true` (command overridable by `LABSHELF_CLOSE_GATE` for tests). Gate fails → fail, nothing committed.
  3. Per spec in session order, read `.git/labshelf-runs/<plan>/<id>.report.yaml`. `status: done` → stage only its `edit`, `create` and in-place test paths and commit: subject = spec `goal`, body `Package <id> of plan <slug>`, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; emit `commit` with `hash` and `files`.
  4. Other status or no report → write `git diff` of its paths plus new files to `.git/labshelf-runs/<plan>/<id>.patch`, restore those paths (delete new files), set the session `status: blocked` and `blocked_reason` naming the spec and status.
  5. Append one line to `log.md`; when every spec is done set `status: done` and delete the session file; then commit remaining changes inside `owns` as `Session <id> review fixes` (same trailer).
  6. Emit `session_closed` with `status` and `commits`.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/plans/__tests__/planClose.test.mjs` passes on temp repos: two done specs → two commits with exactly their paths and the spec message, then review fixes; a file outside `owns` fails with no commit; a `missing` report → patch saved, paths restored, session blocked.
- **Do not touch:** `planRed.mjs`, `planStart.mjs`, `runPlan.mjs`.
