## 9.1 — Match core and `dup-guard` hook

- **Read only:** plan.md D2, D11, D14; `research/index-bench.md`; `research/conventions.md` § Hooks; `research/telemetry-events.md` (`dup_check`, `dup_warning`); `scripts/code/facts.mjs:155-192` (`similar`), `tokens.mjs`, `lib.mjs`; `.claude/hooks/check-handoff.mjs` (`additionalContext`).
- **Decided:**
  - `scripts/code/match.mjs`: `unitsOfSource(path, text)` parses with `ts.createSourceFile` (no program) and returns function-like units (functions, named arrows, methods as `Owner.method`) with lines and `unitFingerprint`; `matchPrint(db, print, {excludeFile, name})` returns hits `{unit, exact, similarity}` over units with ≥ 10 nodes in other files. `facts similar` uses it (same output as before).
  - `.claude/hooks/dup-guard.mjs` (PostToolUse `Edit|Write|MultiEdit`): acts only when the DB exists, `LABSHELF_DUP_GUARD` is not `off` and the path is `packages/*/src/**/*.ts(x)` (not `.d.ts`). Changed units = units of the file after the edit whose lines overlap each `new_string` (Edit, MultiEdit) or all units (Write); skip units under 10 nodes. Warn when a match has exact T1/T2 or similarity ≥ 0.8, or the same name with ≥ 0.6. ≤ 3 `additionalContext` lines: `possible duplicate: <name> (<path>:<line>) ≈ <path>:<line> <name> <signature> (<score>, exported|private): reuse or extend it, or say why not in the report`. A pair already warned for this agent is not repeated. Never denies; error → silent exit 0. Emits `dup_check` (`units`, `warned`, `ms`) on every check and `dup_warning` (`unit`, `match`, `score`, `reason`: exact, similar, name) per line. Register after the test passes (timeout 5 s).
- **Done when:** `node scripts/agents/run.mjs test tooling -- .claude/hooks/__tests__/dup-guard.test.mjs scripts/code/__tests__/match.test.mjs` passes on the session 8 fixture plus a longer function: an Edit adding its renamed copy elsewhere warns with the original's `path:line`; a same-named function at ≥ 0.6 warns; an unrelated function, a `scripts/` path, `LABSHELF_DUP_GUARD=off` and a missing DB give no output; a repeated edit does not repeat it; a warm run < 1 s. `facts similar` output unchanged.
- **Do not touch:** the `extract.mjs` schema, `tokens.mjs` fingerprints, other hooks.
