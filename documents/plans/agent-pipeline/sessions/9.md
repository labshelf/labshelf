## 9.1 — Chunks, embeddings, `ctx q`

- **Read only:** plan.md D12; `research/findings.md` § Index feasibility (ollama embed call, sizes); `research/conventions.md`; `scripts/ctx/db.mjs`, `build.mjs`, `ctx.mjs` (exports and table layout from session 8).
- **Decided:**
  - Chunks: one per top-level declaration, text = file header + declaration source (truncate at 2,000 chars); table `chunks(id, path, name, start, end, text, hash)`, FTS5 table over `text`, `vectors(chunk_id, dim, blob)` as Float32 little-endian.
  - Embeddings: `POST http://localhost:11434/api/embed {"model":"nomic-embed-text","input":[…]}`, batches of 64, only for chunks whose hash changed. Before embedding, `GET /api/tags` with a 1 s timeout; when down, skip embeddings (FTS still updated) and say so in the build line. The embed function is injectable (`buildIndex(root, db, {embed})`) so tests stub it.
  - `ctx q "<text>"`: FTS5 `bm25` top 50 and, when vectors and ollama exist, cosine top 50 over all vectors; merge by reciprocal rank (k = 60); print `path:start-end name` plus the first lines of each chunk until about 32,000 chars (≈ 8k tokens), then `… N more`. Without ollama: FTS only, same format. Emit `index_query` with `query_kind: q`.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/ctx/__tests__/query.test.mjs` passes with a stubbed embed: only changed chunks embedded on rebuild; hybrid result ranks the expected chunk first; output ≤ 32,000 chars; with embed unavailable the query still returns FTS results.
- **Do not touch:** `scripts/ctx/resolve.mjs`, `scripts/plans/`, `.claude/`.

## 9.2 — Local summary in `run.mjs cmd`

- **Read only:** `research/findings.md` § agent-telemetry (local model convention: model, endpoint, `stream:false`, `think:false`, `temperature:0`, `/api/tags` check); `scripts/agents/run.mjs` (the `cmd` kind from session 2); `scripts/agents/__tests__/run.test.mjs`.
- **Decided:** for `cmd` output not recognised as jest, tsc or TAP and longer than 60 lines: if ollama is up, `POST /api/chat` with `qwen3.5:9b`, the conventions above, a system prompt asking for the errors and the final state in at most 30 lines, input truncated to the last 400 lines; on timeout (20 s) or ollama down, print the first 10 and last 25 lines. Always print the log path and keep the exit code. The chat function is injectable for tests.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/agents/__tests__/run.test.mjs` passes with new cases: stubbed model summary used for a 200-line log; head/tail when the model is down; short logs printed as is; log path always printed.
- **Do not touch:** the jest, tsc and TAP parsers, `scripts/ctx/`.
