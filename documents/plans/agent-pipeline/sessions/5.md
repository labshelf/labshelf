## 5.1 — `planFiles`, `plan new`, `plan lint`

- **Goal:** load and save plan and session YAML through the validators; create a plan skeleton; lint a plan.
- **Read only:** `research/schemas.md` (plan/v1, session/v1, spec/v1), `research/conventions.md`; `scripts/agents/schemas.mjs` (exports); `scripts/codemods/shared.mjs` (`parseArgs`); `documents/plans/agent-pipeline/log.md` (header comment to reproduce).
- **Decided:**
  - `scripts/plans/planFiles.mjs`: `loadPlan(dir)`, `loadSession(dir, id)`, `savePlan(dir, plan)`, `saveSession(dir, session)`; load validates and throws with the errors; save writes YAML with `schema` first.
  - `plan new <slug> --level N2|N3 [--title <t>]` (`planNew.mjs`): creates `documents/plans/<slug>/plan.yaml` (status draft), `sessions/1.yaml` (status pending, no packages), `log.md`, empty `research/`; content generated in code, no template files; refuses an existing dir.
  - `plan lint <dir>` (`planLint.mjs`): prints nothing and exits 0 on success; else one line per problem, exit 1. Checks: schema of plan and every session; unique session and spec ids; `depends_on` targets exist and have no cycle (sessions and specs); specs of one session not ordered by `depends_on` have disjoint `edit`/`create` (folder entries cover their contents); every spec `edit`/`create` path inside its session `owns`; every plan acceptance id appears in some spec; every `tests.hidden` file exists and every acceptance id of the spec starts at least one test name in its hidden tests (`it("A2 …"`, `test("A2 …"`).
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/plans/__tests__/planLint.test.mjs scripts/plans/__tests__/planNew.test.mjs` passes: `plan new` output passes lint; a fixture with overlapping `edit` in parallel packages fails; an acceptance id with no test name fails; a valid fixture prints nothing.
- **Do not touch:** `scripts/plans/runPlan.mjs`, `documents/plans/TEMPLATE/`.

## 5.2 — `plan from-brief`, `plan prompt`, `plan stale`

- **Goal:** turn a `brief/v1` into a draft spec, render the implementer prompt for a spec, and detect specs whose facts are stale.
- **Read only:** `research/schemas.md` (brief/v1, spec/v1, the `from-brief` note), `research/conventions.md`; `scripts/plans/planFiles.mjs` and `plan.mjs` (5.1).
- **Decided:**
  - `plan from-brief <brief.yaml> --spec <id> [--session <sid>]` (`planFromBrief.mjs`): adds or merges a spec in the session file with `edit`, `read`, `callers`, `commands` and `sha` from the brief, `plan` from the dir; leaves `goal`, `acceptance`, `seams`, `decided`, `tests` empty for the orchestrator. Merging never drops existing entries.
  - `plan prompt <session> <id>` (`planPrompt.mjs`): prints a 3-line header (plan slug and session, spec id and goal, "Edit only spec paths; tests are hidden"), the spec as a ```` ```yaml spec/v1 ```` block, and the last line `Return report/v1.`
  - `plan stale <session> <id>` (`planStale.mjs`): `git diff --name-only <sha>..HEAD` over the spec's `edit`, `read` and `callers` paths; exit 0 silent when none changed, exit 1 listing changed paths.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/plans/__tests__/planFromBrief.test.mjs scripts/plans/__tests__/planPrompt.test.mjs scripts/plans/__tests__/planStale.test.mjs` passes (temp git repo: prompt block passes `validate("spec", …)`; stale reports a file changed after `sha`, silent otherwise).
- **Do not touch:** `scripts/plans/runPlan.mjs`, `.claude/`.
