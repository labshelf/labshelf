## 2.1 — `run.mjs` wrapper

- **Goal:** `node scripts/agents/run.mjs <kind> …` runs a command, keeps the full log, prints ≤ 40 summary lines plus the log path and keeps the exit code.
- **Read only:** `research/conventions.md`, `research/findings.md` § Repo tooling (jest and tsc per package, gate), `research/telemetry-events.md` (`test_run`, `test_blocked`); `scripts/lint/gate.mjs` (package → `pnpm --filter`); root `package.json:8` (`test:tooling` globs).
- **Decided:**
  - Kinds: `test <pkg|tooling> [--spec <id> --plan <slug>] -- <paths/args>`, `typecheck <pkg>`, `build <pkg>`, `cmd -- <any command>`. `<pkg>` is the folder name under `packages/`; `tooling` runs `node --test` on the given paths (default: the `test:tooling` globs).
  - Full log to `.git/labshelf-logs/<stamp>-<kind>.log` (override `LABSHELF_LOGS_DIR`).
  - jest: add `--json --outputFile <tmp>`; print failing test names, expected/received, and the first stack frame outside `node_modules` and outside test files. tsc: lines `file(l,c): error TSxxxx`, grouped by file, at most 20. node --test: TAP summary (totals, failing names, first assertion line). `cmd`: head and tail of the log (session 9 adds the local summary).
  - Progress (D5), only with `--spec`: state `.git/labshelf-runs/<plan>/<id>.json` (override `LABSHELF_RUNS_DIR`) = list of runs `{ts, failing: [names], exit}`. Before running: if the last 2 runs did not shrink the failing set relative to the run before them, or 5 runs exist, print `BLOCKED: return report status blocked_tests` and exit 3 without running. Emit `test_run` per run and `test_blocked` with `reason` `no_progress` | `max_runs`.
- **Done when:** `node --test scripts/agents/__tests__/run.test.mjs` passes, covering: fixture failing jest JSON and tsc output give ≤ 40 lines and the original exit code; log file written; block after two non-shrinking runs and after five runs, exit 3.
- **Do not touch:** `scripts/lint/`, `.claude/`.

## 2.2 — Bash guard and command texts

- **Goal:** `.claude/hooks/guard-bash.mjs` (PreToolUse Bash) denies raw test, typecheck and build commands and names the `run.mjs` equivalent; every agent-facing text uses the wrapper.
- **Read only:** `research/conventions.md` § Hooks; `.claude/hooks/guard-processes.sh` (deny shape); `.claude/settings.json`; `scripts/agents/run.mjs` usage (2.1).
- **Decided:**
  - Deny: raw `jest`, `tsc`, `pnpm --filter <pkg> test|typecheck|build`, `pnpm test`, `pnpm test:tooling`, `node --test` (not when the command is a `run.mjs` call). Allow `pnpm gate` and everything else. Check each segment of `&&`/`;`/`|` chains.
  - Reason: `Use: node scripts/agents/run.mjs <equivalent>`, e.g. `pnpm --filter @labshelf/core test -- x` → `node scripts/agents/run.mjs test core -- x`.
  - Then replace raw commands in the texts listed by `rg --hidden -n 'pnpm --filter|pnpm test|node --test' .claude scripts/plans` (expected: `implementer.md` step 6, `diagnoser.md`, `scripts/plans/runPlan.mjs:67-83` UNATTENDED, `.claude/skills/finish/`). Hook tests and `guard-bash.mjs` are exempt.
  - Register in `.claude/settings.json` next to `guard-processes.sh` after the test passes.
- **Done when:** `node scripts/agents/run.mjs test tooling -- .claude/hooks/__tests__/guard-bash.test.mjs` passes (raw core test denied with the wrapper command in the reason, `pnpm gate` allowed, `run.mjs` allowed, chained command denied); the rg above lists only exempt files.
- **Do not touch:** `scripts/lint/gate.mjs`, the other hooks.
