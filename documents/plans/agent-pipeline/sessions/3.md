## 3.1 — `schemas.mjs`

- **Goal:** `scripts/agents/schemas.mjs` exports `KINDS`, `parseBlocks(text)` → `{kind: value}` from ```` ```yaml <kind>/v1 ```` fenced blocks (parsed with `yaml`), and `validate(kind, value)` → `string[]` errors (empty = valid).
- **Read only:** `research/schemas.md` (the only source of fields), `research/conventions.md` § Scripts.
- **Decided:** hand-written validators, no zod (D3); unknown keys, missing required keys, wrong enum values and wrong types are errors naming the field path (`packages[0].edit[1].path`); `lines` matches `^\d+-\d+$`; ids are strings; `session.packages[]` are specs without `schema`; `tests` is `{hidden, command}` or `{none}`; a YAML syntax error is an error, not a throw. Fixtures `scripts/agents/__tests__/fixtures/schemas/<kind>/{valid,invalid}-*.yaml`, at least one of each per kind.
- **Done when:** `node scripts/agents/run.mjs test tooling -- scripts/agents/__tests__/schemas.test.mjs` passes.
- **Do not touch:** `.claude/`.

## 3.2 — Agent definitions

- **Goal:** each agent returns exactly one block of its kind (`research/schemas.md`); `tester` and `arbiter` exist.
- **Read only:** `research/schemas.md`, `research/conventions.md`, plan.md D2, D5, D6, D9; current `.claude/agents/explorer.md`, `implementer.md`, `diagnoser.md`, `finisher.md`.
- **Decided:**
  - `explorer.md`: returns `brief/v1`; looks up code with `node scripts/ctx/ctx.mjs def|refs|q` when that file exists, else `rg`; may search longer.
  - `implementer.md`: with a `spec/v1` block in the prompt, reads and edits only spec paths, never reads or writes tests, runs only the spec's `tests.command` and `commands`, and reports gaps as `status: missing`; without a spec, follows the brief as today. Always returns `report/v1`. Drop the reuse-search step (step 2).
  - `diagnoser.md`: same loop as today, runs commands through `run.mjs`, returns `diagnosis/v1` whose `spec` is ready for an implementer.
  - New `tester.md`: at plan time, from the spec only, writes tests into `documents/plans/<slug>/tests/<spec-id>/<mirrored repo path>`; every test name starts with its acceptance id and a space (`A2 rejects …`); returns `report/v1`.
  - New `arbiter.md`: read-only; reads the spec, the hidden tests, the log path and `git diff`; returns `verdict/v1`; never edits.
  - `finisher.md` unchanged. Frontmatter `model`: tester sonnet, arbiter opus.
- **Done when:** `rg --hidden -w diagnose .claude scripts documents` finds no agent reference; for each of the five files, the example block passes `validate` (`node -e` with `parseBlocks`).
- **Do not touch:** `.claude/skills/`, `.claude/hooks/`.

## 3.3 — `check-handoff` hook

- **Goal:** `.claude/hooks/check-handoff.mjs` (SubagentStop) blocks a subagent whose final message lacks a valid block for its type.
- **Read only:** `research/conventions.md` § Hooks, `research/findings.md` § Claude Code (SubagentStop input, transcript path), `research/hook-probes.md` (P2), `research/telemetry-events.md`; `.claude/hooks/context-budget.mjs:40-80`.
- **Decided:**
  - Kind by `agent_type`: explorer → brief, implementer → report, tester → report, diagnoser → diagnosis, arbiter → verdict; other types pass silently (D2).
  - Reads `last_assistant_message`; missing or invalid block → `{"decision":"block","reason":<errors>}`. At most 2 blocks per `agent_id` (state per conventions); the third time let it through and emit `handoff_invalid`.
  - Implementer `status: done` with a spec (first user line of the transcript) that has `tests.command`: the last run in `.git/labshelf-runs/<plan>/<id>.json` must have `exit: 0`, else block with "last test run is not green".
  - Valid implementer report → save to `.git/labshelf-runs/<plan>/<id>.report.yaml`; emit `package_report`, `missing` (status missing), `arbiter_verdict` (arbiter).
  - If `research/hook-probes.md` says P2 failed, implement the fallback recorded there instead.
  - Register under `SubagentStop` in `.claude/settings.json` after the tests pass.
- **Done when:** `node scripts/agents/run.mjs test tooling -- .claude/hooks/__tests__/check-handoff.test.mjs` passes (valid passes, invalid blocks with errors, third attempt passes, `done` with red run blocks, unknown type passes, report saved).
- **Do not touch:** `scripts/agents/schemas.mjs`, other hooks.
