## 4.1 — `spec-guard` hook

- **Goal:** `.claude/hooks/spec-guard.mjs`, PreToolUse on `Read|Edit|Write|MultiEdit|NotebookEdit|Grep|Glob|Bash`, denies tool calls outside the agent's spec.
- **Read only:** `research/conventions.md` § Hooks (input, deny shape, transcript path, state dir), `research/schemas.md` § spec/v1, `research/telemetry-events.md` (`spec_deny`, `index_query`), `research/hook-probes.md` (P1); `scripts/agents/schemas.mjs` (exports only); `.claude/hooks/guard-doc-reads.sh` (how `documents/` reads go through `doc.mjs`).
- **Decided:**
  - Acts only for `agent_type` `implementer`, `tester`, `arbiter`, and only when the subagent's first prompt line holds a valid `spec/v1` block (D2). Otherwise exit 0 with no output. Parse the spec once per `agent_id` and cache it in the hook state dir.
  - Paths are normalised to repo-relative before matching; a folder entry in `create` covers everything under it; `lines` ranges do not restrict access (whole file).
  - **Hidden tests:** the spec's `tests.hidden` paths and anything under `documents/plans/*/tests/` are denied to the implementer for every tool, including any Bash command that names them.
  - **implementer:** Read only paths in `edit`, `read`, `create` (and `documents/` reads via `node scripts/docs/doc.mjs`); Edit/Write/MultiEdit/NotebookEdit only paths in `edit` or `create`; Grep and Glob denied. Bash allowlist: the spec's `tests.command`, each entry of `commands`, `node scripts/agents/run.mjs … --spec <own id>`, `node scripts/docs/doc.mjs …`, `git diff` and `git status` limited to own paths (or no path), `node scripts/ctx/ctx.mjs def|refs|q …` with a quota of 10 per agent (emit `index_query` per allowed call, deny after 10). Anything else denied.
  - **tester:** Read as implementer plus its own tests dir; Edit/Write only under `documents/plans/<plan>/tests/<own id>/`; Bash only `run.mjs` and `doc.mjs`.
  - **arbiter:** Read spec paths, hidden tests and `.git/labshelf-logs/`; no Edit/Write; Bash only `node scripts/agents/run.mjs …` and `git diff …`.
  - Deny reason (all cases): `Outside your spec: return report/v1 with status missing and say what you needed.` Each deny emits `spec_deny` with `tool` and `target`.
  - Register in `.claude/settings.json` under PreToolUse with matcher `Read|Edit|Write|MultiEdit|NotebookEdit|Grep|Glob|Bash`, after the tests pass; keep the existing guards.
- **Done when:** `node scripts/agents/run.mjs test tooling -- .claude/hooks/__tests__/spec-guard.test.mjs` passes, covering: implementer with spec reads an `edit` path (allowed) and an outside path (denied with the reason); Write outside `create` denied; hidden test denied for Read and for `cat` via Bash; Grep denied; `tests.command` allowed; 11th `ctx` call denied; tester writes in its tests dir only; arbiter Edit denied; implementer without a spec block and `explorer` with one pass untouched.
- **Do not touch:** other hooks, `scripts/agents/`.
