## S5.2 — GitHub client

- **Do:** `core/src/github/` with injected fetch and token. Create or reuse the user's fork, wait until it answers, read the base sha, create blobs (base64), a tree under `templates/<id>/`, a commit, a branch `template/<id>-<date>` and a pull request. Return its URL. Errors carry the step, status and GitHub message.
- **Touch:** `core/src/github/**`, tests. **Do not touch:** the sync auth stores (a GitHub token never goes into `TokenStore`).
- **Test first:** fake fetch for the happy path; fork already exists; 403 and 422 mapped to messages; a fork not ready yet, then ready.
- **Done when:** tests pass.
