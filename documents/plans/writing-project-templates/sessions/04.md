- **Do:** `scripts/template-catalog.mjs` bundles the S1.2 validator into `validate.mjs` and an index builder (walk the folders, hash the files, write `index.json`) into `build-index.mjs`, both with esbuild and no runtime dependency. One validator exists, in core.
- **Touch:** `scripts/`, the core export it needs, tests under the tooling suite. **Do not touch:** app code.
- **Test first:** a fixture catalog with one bad manifest, one `..` path and one oversized image → each named in the output with a non-zero exit; a good catalog → a stable `index.json`.
- **Done when:** `pnpm test:tooling` passes.
