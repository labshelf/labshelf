## 1.1 — Writing view: "Only on Drive — download to…"

- **Goal:** show each Drive-only project as a Writing view row whose action downloads it where the user chooses (D2: external paths are device-local, so the target is chosen per device).
- **Read only:**
  - `packages/core/src/sync/engine/syncTypes.ts` (the `projectsOnlyOnDrive` field of the run result);
  - `packages/vscode/src/sync/adapter/syncController.ts` (keeps the last run result);
  - `packages/vscode/src/writing/projectsTreeProvider.ts` (Writing view rows);
  - `documents/contracts/sync.md`, section "projects" ("Only on Drive": never downloaded on its own; the user chooses where it goes).
- **Decided:**
  - Each id in `projectsOnlyOnDrive` from the last sync run is a Writing view row labelled "Only on Drive — download to…".
  - The row's action asks where the project goes: under `<library>/projects/`, or into a folder the user picks, which is then registered as an external project.
  - The download is the engine's normal sync of that project once it is in the list; nothing downloads on its own.
  - The row disappears once the project exists on disk.
  - Failures are logged through the injected `ILogger` and shown as a toast with context.
- **Done when:** `pnpm --filter @labshelf/vscode typecheck` passes (and core's, if touched). No test: this is view and command glue.
- **Do not touch:** `documents/contracts/`, `packages/browser`, `packages/terminal`.
