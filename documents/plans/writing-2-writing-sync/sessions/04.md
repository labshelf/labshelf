## S13 — Comments format and anchoring

- **Do:** in `core/src/writing/comments/`, the `<project>/.labshelf/comments.json` shape `{threads: [{id, file, anchor: {quote, prefix, suffix}, comments: [{author, body, createdAt}], resolved}]}` with stable key order. Each comment is anchored to the quoted text with context, not to a line number (D6). Re-anchor on load by exact quote, then fuzzy match; an anchor that cannot be found becomes "detached" and stays listed. The file syncs and merges like any text file (D3). Add `.labshelf/comments.json` to [library-format.md](../../../contracts/library-format.md) in this step.
- **Touch:** `packages/core/src/writing/comments/`, `packages/core/__tests__/writing/comments/`, the contract file. **Do not touch:** `packages/vscode`, the sync engine.
