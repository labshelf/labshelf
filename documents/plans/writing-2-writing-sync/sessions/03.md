## S9 — Share a project with a coauthor

- **Do:**
  - A "Share project" action: the owner's LabShelf creates one exchange file on Drive and shares it; the coauthor picks it once in Google Picker (a browser page signed in to Google, with an API key and the Picker API on the LabShelf Cloud project); each sync merges the other author's changes from it. Why this shape: Q1 in `../plan.md` (`drive.file` grants are per person and per file; the full `drive` scope is out).
  - The exchange sits behind one core port so another transport (such as GitHub) can be added later; only the Drive one is built (D8).
  - The merge uses the base store and three-way merge from session 2.
- **Touch:** `packages/core/src/sync/` (exchange port and Drive adapter), `packages/vscode/src/writing/` and `packages/vscode/src/sync/` for the action; contract: [sync.md](../../../contracts/sync.md) gets the exchange file in this step. **Do not touch:** `packages/browser`, `packages/terminal`.
- **Done when:** a second account, after picking the exchange file once, syncs the project and sees the owner's changes, and the owner sees theirs; checked on a scratch Drive with two accounts.
