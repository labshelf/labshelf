# Rebuttal helper

After a submission, reviewers send comments, and the authors answer them point by point in a response letter. LabShelf could organise that work inside the writing project.

The author pastes the reviews. LabShelf splits them per reviewer and per numbered or bulleted point, and the author can correct the split. Each point carries a status (open, addressed, won't fix), the author's reply, and links to the places in the source where it was handled; those links would use the anchored comments of plan `project-collaboration`. The rebuttal round is stored with the project, so it follows the author across machines.

"Export response" writes the letter in Markdown or LaTeX: each reviewer point quoted, the reply under it, and the passages that changed between the submitted version and the current one, taken from the existing version compare.
