# LabShelf

LabShelf is a workspace for scientific research that connects reading papers, developing ideas and writing technical documents.

It is built for researchers and students who work with equations and code and usually write in LaTeX or Typst. Research often means moving between a reference manager, a manuscript editor, a computational notebook and a conversation with an advisor. LabShelf aims to keep that work connected, so sources, calculations and discussions remain useful as the research develops.

The Library holds papers and their annotations. Projects hold manuscripts and their supporting work. Optional Spaces bring papers, projects, notes and research context together around a topic or effort.

LabShelf runs in the browser, VS Code and the terminal, with capabilities suited to each. It is local-first: files remain under the user's control, and their own sync tool can move the library between devices. Collaboration on writing projects is separate from folder synchronization.
